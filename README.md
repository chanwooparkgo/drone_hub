# 드론 정보 사이트
드론 비행 및 활동에 필요한 정보를 한 곳에서 확인할 수 있도록 제작하고 있는 개인 웹 프로젝트입니다.

## 프로젝트 소개

드론을 취미로 활용하면서 생성형 ai를 이용하여 비행 가능 지역, 장소 정보, 오픈채팅방 홍보 등의 정보를 한 곳에서 확인할 수 있는 웹사이트를 제작하고자 시작한 프로젝트입니다.

Django를 기반으로 웹페이지를 구성하고 Kakao Maps API 등을 활용하여 지도 기반 기능을 구현하고 있습니다.

## 주요 기능(넣고자하는것)

- 드론 비행 지도
- 현재 위치 검색
- 장소 공유
- 드론 중고거래 정보
- 드론 모임 정보
- Kakao Maps API 활용
- Django 기반 웹페이지 구성

## 개발 환경

- Python
- Django
- HTML
- CSS
- JavaScript
- Kakao Maps API

## 프로젝트 진행 현황

현재 기능을 추가하고 개선하며 개발을 진행하고 있는 개인 프로젝트입니다.
